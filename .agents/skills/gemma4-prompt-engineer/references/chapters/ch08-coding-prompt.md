## 8. Coding Prompt

Gemma 4 適合 coding 與 code review 類任務。提示要避免只說「幫我寫」或「幫我看」，而要指定語言、框架、輸入輸出、錯誤處理、測試與限制。

### 程式碼生成範本

```text
請使用 [語言/框架] 撰寫 [功能]。

需求：
1. …
2. …
3. …

限制：
- 使用 [版本]
- 不使用 [禁止套件/做法]
- 錯誤處理必須包含 …
- 輸入格式：…
- 輸出格式：…

請輸出：
1. 完整程式碼
2. 使用範例
3. 重要設計說明
4. 邊界情況
```

### Code Review 範本

```text
請審查以下程式碼，重點放在：

1. 潛在 bug
2. 安全漏洞
3. 效能問題
4. 可維護性
5. 錯誤處理
6. 邊界情況

要求：
- 指出具體位置
- 說明為什麼是問題
- 提供可執行的修正建議
- 若沒有問題，請明確說明

程式碼：
...
```

### Debug 範本

```text
這段程式碼出現問題。

預期行為：
...

實際行為：
...

錯誤訊息：
...

我已經確認：
- ...
- ...

請幫我：
1. 推測最可能原因
2. 說明排查順序
3. 提供修正版本
4. 補充避免再次發生的測試案例

程式碼：
...
```

### 單元測試範本

```text
請使用 [測試框架] 為以下函式撰寫單元測試。

測試需包含：
1. 正常情境
2. 邊界情境
3. 錯誤情境
4. 空值或格式錯誤
5. 權限或安全相關情境（若適用）

函式：
...
```

### 程式碼轉換範本

```text
請將以下 [來源語言] 程式碼轉成 [目標語言]。

要求：
- 保留原本邏輯
- 使用目標語言慣用寫法
- 標示任何無法 1:1 對應的地方
- 不要改變業務規則

來源程式碼：
...
```
