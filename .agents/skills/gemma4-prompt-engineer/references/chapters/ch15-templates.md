## 15. Prompt Templates

本章範本主要用於落地實作，部分範本是依官方格式整理，部分則是第三方實務常見寫法。

### 15.1 通用任務範本

```text
你是 [角色]。請完成 [任務]。

背景：
[背景]

輸入：
[資料]

要求：
1. [要求 1]
2. [要求 2]
3. [要求 3]

限制：
- [限制 1]
- [限制 2]
- 若資訊不足，請說明缺少什麼，不要猜測。

輸出格式：
[格式]
```

### 15.2 技術決策分析範本

```text
你是技術架構審查者。請分析以下技術決策。

背景：
...

候選方案：
A. ...
B. ...
C. ...

評估面向：
1. 成本
2. 維運複雜度
3. 安全性
4. 效能
5. 可擴展性
6. 團隊熟悉度
7. 長期風險

輸出：
- 一段總結
- 比較表
- 推薦方案
- 主要風險
- 待確認問題
```

### 15.3 Code Review 範本

```text
你是資深工程師。請審查以下程式碼。

重點：
1. Bug
2. Security
3. Performance
4. Maintainability
5. Error handling
6. Edge cases

請用表格輸出：
| 類型 | 位置 | 問題 | 影響 | 建議 |

程式碼：
...
```

### [第三方實務] 15.4 JSON 抽取範本

```text
你是一個 JSON-only data extraction API。
只輸出有效 JSON，不要 Markdown，不要解釋。

Schema:
...

抽取規則：
- 找不到的欄位填 null
- 不要猜測
- 保留原文中的單位與幣別

輸入：
...
```

### 15.5 圖片分析範本

```text
請分析這張圖片。

請輸出：
1. 圖片整體描述
2. 主要物件與位置
3. 可見文字
4. 可能情境
5. 不確定或無法辨識的部分

限制：
- 不要猜測看不到的內容
- 對不確定項目標示「不確定」
```

### [第三方實務] 15.6 工具代理範本

```text
你是一個可使用工具的助理。

規則：
- 當問題需要外部資料、計算或查詢時，使用工具。
- 不要猜測工具應提供的資料。
- 工具失敗時，說明失敗原因並詢問下一步。
- 最多執行 [N] 步。
- 最終答案需根據工具結果。

可用工具：
[工具 schema]
```
