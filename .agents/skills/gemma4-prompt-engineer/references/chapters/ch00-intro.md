# Gemma 4 Prompt Guide

版本：v1.0  
日期：2026-06-30  
定位：Reference Guide  
範圍：Gemma 4 提示引導、提示格式、思考模式、結構化輸出、工具使用、文字/圖片/音訊提示、程式設計與文件分析提示範本。  
不納入：其他模型比較、與 Gemma 無直接關聯的提示工程技巧、無來源依據的內容；少量編者延伸建議會明確標示。

## 0. 文件使用方式

這份文件不是「50 個提示詞合集」，而是把 Gemma 4 的提示引導整理成可長期查閱的 Reference Guide。閱讀順序建議如下：

1. 先讀第 1～3 章，理解 Gemma 4 的提示格式、角色、控制 token 與上下文組織。
2. 需要處理複雜推理時讀第 4 章。
3. 需要穩定 JSON、工具呼叫、代理流程時讀第 5～6 章。
4. 需要處理圖片、音訊、多模態資料時讀第 7 章。
5. 實作任務時直接查第 8～13 章的範本與檢查表。

### 來源標註規則

#### 來源類型

本文件把來源分成兩種：

- **官方來源**：Google AI for Developers / Google DeepMind 的 Gemma 文件。
- **部落格來源**：`gemma4-ai.com` 的部落格文章。此網站是社群/第三方資料，不為官方文件（僅作實務參考）。

#### 來源 ID 規則

- `S-01`～`S-06`：Gemma 官方資料
- `S-51`～`S-57`：gemma4-ai.com 部落格資料

每章末尾皆列出來源 ID。來源 ID 可在 `references.json` 查到完整標題、網址與來源類型，也可在 `source-map.json` 查到各章使用了哪些來源。

#### 重點段落標籤

若某個建議來自官方文件，會優先標為「官方」。若是部落格提供的實務範例或經驗整理，會標為「部落格」。

針對少數容易被誤認為官方規格的重點段落，會額外使用下列標籤：

- **[官方]**：可直接對應到 Gemma 官方文件的能力、格式、機制或限制。
- **[第三方實務]**：來自第三方文章的經驗整理、建議或常見做法。
- **[編者建議]**：根據來源整理後的延伸建議，方便實作，但不等於官方明文規範。
