## 9. 文件分析、研究摘要與資料抽取 Prompt

Gemma 4 的長上下文適合文件分析，但提示要明確定義分析層級與輸出格式。

### 文件分析範本

```text
請分析以下文件，輸出：

1. 核心摘要：5 個 bullet
2. 重要日期、金額、期限
3. 風險或異常條款
4. 模糊或需要確認的語句
5. 建議後續確認問題

限制：
- 僅根據文件內容回答
- 不要加入文件外推測
- 若資料不足，標示「資料不足」

文件：
...
```

### 研究摘要範本

```text
請將以下研究文件摘要成三個區塊：

1. Key Finding：2-3 句，說明發現
2. Methodology：2-3 句，說明方法
3. Practical Implications：2-3 句，說明實務意義
4. Limitations：列出作者承認或文件中明示的限制

文件：
...
```

### PDF / 發票資料抽取範本

```text
請從以下文字中抽取發票項目，輸出 JSON。

Schema:
{
  "invoice_number": "...",
  "date": "...",
  "items": [
    {
      "description": "...",
      "quantity": 0,
      "unit_price": 0.00,
      "total": 0.00
    }
  ],
  "subtotal": 0.00,
  "tax": 0.00,
  "total": 0.00
}

限制：
- 找不到的欄位填 null
- 不要猜測不存在的數字
- 金額保留原文件幣別
```
