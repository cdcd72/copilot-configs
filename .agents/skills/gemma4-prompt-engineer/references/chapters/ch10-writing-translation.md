## 10. 寫作、翻譯與中文 Prompt

Gemma 4 的寫作與翻譯提示要提供受眾、語氣、用途與禁用風格。

### 寫作範本

```text
請寫一篇 [長度] 的 [文章類型]，主題是 [主題]。

目標讀者：
...

語氣：
...

必須包含：
1. ...
2. ...
3. ...

避免：
- 不要使用空泛企業腔
- 不要使用陳腔濫調
- 不要從抽象大敘事開頭
- 不要捏造資料

輸出格式：
...
```

### 重寫範本

```text
請重寫以下文字，使其更清楚、更精簡。

要求：
- 保留原意
- 字數減少約 30%
- 語氣維持 [正式/友善/技術/中立]
- 不新增原文沒有的資訊

原文：
...
```

### 翻譯範本

```text
請將以下文字翻譯成 [目標語言]。

目標讀者：
...

語氣：
...

領域：
...

術語要求：
- [term A] 翻成 [...]
- [term B] 保留原文

限制：
- 不要逐字死譯
- 不要改變事實
- 若原文有歧義，請在譯文後列出歧義點

原文：
...
```

### [第三方實務] 中文任務注意事項

1. 若要繁體中文，明確指定「繁體中文（台灣用語）」。
2. 若要工程文件，指定術語是否保留英文。
3. 若要正式文件，指定語氣「專業、簡潔、不口語」。
4. 若要社群貼文，指定平台與字數限制。
5. 對翻譯任務，提供目標讀者比單純說「翻譯」更穩定。
